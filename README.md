# Prediccion_sequia
Aplicación web que hace un análisis en tiempo real: 
Capacidad probada para recibir coordenadas, obtener una imagen satelital actual de GEE y procesarla en segundos. 
Predicción inteligente: integración exitosa de un modelo de IA que clasifica el riesgo de sequía basándose en patrones visuales aprendidos de datos históricos.
